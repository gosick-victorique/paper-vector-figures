# 混合视觉语法

文件名保留兼容。2D与3D按各自能解释的关系组合，不规定整图的立体比例。

## 按信息任务选择表示

| 信息任务 | 适合的表达 | 容易误读的地方 |
|---|---|---|
| 文本、代码、证据 | 字词/token编辑用实际内容与固定跨度；连续嵌入更新用坐标或向量，原句保留角色 | [ProAda](cases/proada.md)的嵌入候选不虚构为改写句子；空间例须说明是否来自模型。浅叠层不表示排名 |
| 序列、视角、尺度 | 保留索引轴，画真正进入计算的元素 | 时间位移不是物理深度；拼接内分量不等于独立token |
| 路由、存储、图结构 | 访问矩阵、当前地址、稳定对象身份；局部空间展开 | [WebMirage](cases/webmirage.md)同一内容可换编号，按当前映射连接；索引重组不自动表示搬移，不添加不存在的边 |
| 物理几何、成像 | 装配、射线、曲面、体素、切面 | 展示投影、实际相机、仿真结果分别交代 |
| 特征或目标函数 | 算子支持的低维几何，配正视数值 | 低维例不等于模型特征降维；严格投影、松弛先验、经验净化的保证不同，端点是否落到集合按实际算子表达。[MABT](cases/mabt.md)保留非零残距，预算投影另画 |
| 训练与优化 | 阶段×参数状态、实际更新对象、约束 | 冻结参数不等于截断输入梯度；同一量可只在权重支路detach，主损失仍可微，见[CamoShift](cases/camoshift.md)；示意箭头不是轨迹 |

## 深度的角色

- **物理空间**：真实数据遵守其坐标/相机；直觉光路明确标示意。SLASH用透明装配说明光学前端，正视平面计算投影。
- **张量维度**：标索引或形状。AD²每时刻拼接成一个token，与当前时刻三个相机token不同。
- **特征空间**：选择支持当前算子的几何。PA-Attack余弦可由单位方向解释；原始点积/范数不能随意归一化。LETHE的归一化方差不因整体缩小而下降。
- **数值高度／面积**：给基线、尺度和符号。ReMoE非负贡献可堆叠；解释非负权重乘有符号数值时，可像[Ancestor VLM](cases/ancestor-vla.md)用宽度×相对零线的高度表示带符号面积，各对象共用尺度，精确乘积另保留数字。它服务于乘法解释；只比较最终大小时，等宽条或数表可能更直接，负权重不能直接映为宽度。
- **概念分组／浅厚度**：帮助识别页、阶段、集合，不能暗示概率、物理距离或质量。

参见 [SLASH](cases/slash.md)、[AD²](cases/ad2.md)、[PA-Attack](cases/pa-attack.md)、[LETHE](cases/lethe.md)、[ReMoE](cases/remoe.md)。

## 从名词变为可见操作

| 操作 | 图上应当发生什么 |
|---|---|
| 选择 | 候选、判据、选中集合及未选对象去向；[SAWR](cases/sawr.md)中未被某损失直接计分的子带仍存在，不等于删除或全局停止梯度。汇总边连接实际集合 |
| 对齐／比较 | 真实两侧对象与索引，操作紧邻对应位置 |
| 融合 | 各来源进入实际汇合处，权重贴近被乘的量 |
| 更新 | 同一对象前后状态；可改变量/区域与各目标的比较域分别画出。[MROP](cases/mrop.md)在mask内修改、用区域外重建项和全图TV；某项的支持不能套给全部目标 |
| 共享 | 共享对象出现一次，标出生成来源，再接各受体的真实运算；保留不同输入/输出。[Ancestor VLM](cases/ancestor-vla.md)将一侧计算的权重对齐复用于两侧，不因排版对称而重算 |
| 转换 | 同一内容贯穿不同表示，说明转换顺序和范围 |

距离或一致性目标可用共用标尺、端点和差值配对解释，保留平方、权重与归约。logit与概率等不同量分别命名，参见[AdvPCS](cases/advpcs.md)；中间质量也不自动是概率。[IAU-FOA](cases/iau-foa.md)将原始运输质量、总量归一化权重和最终加权读出分开，保留小非零项。求解权重的正则目标不自动加入最终loss；当前反传固定的权重支路与可微数值支路可以分路表示。

学习输出未给定时，可用符号输入、投影、门控和汇合展示值流；按同一对象ID接回原状态，不必填入无依据的彩色特征数值。[Tetris3D](cases/tetris3d.md)用这种方式展开逐体素残差注入，保留置零之后的投影。

来源身份与局部位置是不同条件时，可分开显示两次选择，再接到真实融合处；例如[SAM-V](cases/samv.md)的视图token和同视图patch。拼接须确认所沿的轴：合并通道与增加token数量应呈现不同结构。

只展开当前关键操作。Anti-I2V是Lab后再DCT的串行转换；PA权重乘token目标，MAC标量乘输入扰动。形似的权重图不能替代作用对象判断。详见[案例入口](worked-mechanisms.md)。

## 具体对象的造型

选择能体现机制的轮廓、部件和局部内容。AdvTiles用肩腰和四肢改善圆柱人体；SIGN让连续场景供定位、同源采样供像素操作；FeatureFool用更大的帆面与索具改善主体辨识。造型变化不自动表示算法改变形状，重画源内容后要重算相关数据。

同对象跨视图复用几何、纹理、ID和坐标。曲面UV按映射放置，不能重新填随机格；CertMask周期边界片段仍属于原对象。颜色是数据时可用轮廓、缩短和遮挡表现深度，中性上下文才自由加明暗；NORP保留正视UV供查询。

### 视角与透明层次

同组对比用共同投影。先让重要端点、方向、轮廓与内部目标分开，再微调空间感；可移动展示相机，不移动数据点来避让。PA-Attack R7保留六向量，换视角分开近共线投影。屏幕角度/距离不作原空间度量，数字、色阶和密集读数保持正视。

透明面回答“里面有什么”或“哪个平面在前”，关键边与对象保持清晰，背面网格退一级。稠密透明体优先显示外壳、切片或少量有意义单元，避免重复内面叠色发脏。具体体素起点、遮挡和拆面方法见[空间细节](design-guide.md#透明体素)。真实相机不可换时加局部读图，而非改观测。

## 信息密度不等于装饰密度

优先增加具体数据形态、内部操作、对应关系和条件差异。完整网格只用于定位时，可保留支持域边界、尺寸、选区与坐标，把面积留给同源局部；参见[SAM-V](cases/samv.md)。单元格数值或覆盖关系本身是证据时，不能据此省略。图像裁块与特征位置图可并列，但标明索引对应，前者不冒充学习特征。大底框和厚侧面同样按解释作用取舍；离散token操作按索引展开。

微小变化不靠夸张数据来制造：Anti-I2V保留实际色块，用共同残差轴放大显示；PA局部图保留完整总览，两项小计不替代全部目标。

### 参数尺度与迭代次数

Topo-ADV固定点集扫描半径，之后才改变输入坐标；层片分别表示参数条件和空间约束。算法时间、索引分组和物理深度各自命名。对应[案例](cases/topo-adv.md)。


### 更新箭头的参照对象

[AdvFM](cases/advfm.md)的端点编辑、速度修正和下一状态差由不同缩放及点对定义。先写清每支箭头的起点与终点，再画长度和方向。执行的一步与预测/重建的延长段分开；共享起点的多步长比较不能冒充连续轨迹。用同投影呈现差分，数值负责倍率；论文中的“流形”名词不自动授权添加弯曲表面。


### 观察时间与优化时间

先区分物理运动、采样事件和模型更新。[TARA](cases/tara.md)中纹理跨帧共享，H/M随帧变化，优化期间轨迹固定而纹理更新；[RILA](cases/rila.md)中在线控制递推读取上一灯光向量，相机两帧进入独立估计器。画各阶段实际输入，按原方法决定是否有反馈；空间位移不自动编码时间，事件顺序也不等于实测延迟。由可见支持计算的统计沿用同一几何；阶段图若只标识状态，说明未模拟学习或传感器输出。


### 世界、图像与展示深度

先确定操作发生在世界、图像还是推断结果中。[CamoShift](cases/camoshift.md)在图像中平移目标证据；[Illusion of Depth](cases/illusion-depth.md)从同一采样信号的匹配索引推导三角测量位置，物理表面没有移动。将真实几何、推断假设和展示投影分别命名；候选、读数和几何有计算联系时沿用同一实例，不能只让配色相似。为比较而错开的平行面不代表真实相机间距；未计算的全局输出或学习特征保持符号。
