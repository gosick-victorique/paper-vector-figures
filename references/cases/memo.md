# 案例四：同一证据的两种载体

**来源**：[MEMO v1](https://arxiv.org/html/2609.07471v1)，Query-Conditioned Evidence Extraction、Joint Evidence Selection and Presentation、Working Memory Building。

旧稿用四行选择表解释 text/image/dual/drop，但证据内部只有一个编号。为了说明“来源可追踪”与“双载体互补”，新图沿一条证据展开：

1. 原创源记录包含会议地点变化，以及不相关的前后句。高亮关键字符，将字符范围贴到真正选中的短语下方，不框住整页或附近说明。
2. 中间单元保留 source r2、E2、复制的内容与局部上下文、跨度及保留优先级。文字与源记录保持一致。
3. manager 位于控制层，输入为 q、U、B；示例中 E2 的动作是 dual，版式为 cards。控制连线进入动作标记，数据线从证据单元分叉进入载体，二者不共用同一路径。
4. 文本载体保留原句及来源；视觉载体以带时间的 from/to 卡片表现 room B→room D。相同内容被组织成不同形态，不把示意图的变化误称为新增事实。
5. 两载体共同受预算约束，并与 q 汇入 reader。图只跟踪联合计划中的一个单元，完整动作概览仍可单独保留。

首次草稿暴露两个问题：跨度括号落在不相关句子下方；橙色计划线与绿色证据分叉线重合。修订让括号紧贴 key span，并把控制线接到单元的动作标记。此前把版式称为 timeline、实际却画成前后卡片，也改为 cards。

这个案例适合迁移到检索、文档处理和记忆系统。文字复制可用相同词句证明；数值维度保持可用相同符号证明；来源追踪可用相同 ID 证明。无需为所有卡片附加大量审计字段，只展示这张图要说明的关系。
