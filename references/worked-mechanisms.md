# 按设计问题选案例

这是已试画案例的入口。先选当前难点，读取对应案例即可；它们支持构图决策，不是整图模板。原论文的图形观察见 [参考图谱](reference-atlas.md)，不同表示及其取舍见 [设计指南](design-guide.md)。

近期视觉对抗案例的可视选择见[候选、反馈与共享权重](adversarial-entry.md)，先看局部，再回到此处读取完整机制。

|---|---|---|
| 对象仍保留，但局部运算来源改变 | [P2P](cases/p2p.md) | 同token×深度地图与同层展开；配置区须把候选、边界和集合接通，规划完整不能替代成图评审 |
| 概率、当前选择与跨步状态容易混淆 | [SRIM](cases/srim.md) | 用非最高概率的合法抽样区别排序与抽样；首次赋值、双更新、单槽写入与全体概率重算分别表达 |
| 效果例很清楚，但方法怎样构造仍说不清 | [GCD](cases/gcd.md) | 同查询对的分数面、概率条和判定解释作用；构造区须另追候选量、映射与目标。三版四评委比较；补映射改善完整度，最后一轮仍保留目标动机与密度问题 |

| 两种通道为何比较不同频带 | [SAWR](cases/sawr.md) | H两层递归、E单层低频；完整计分组连接读数，未计分子带保留存在 |

## 怎样迁移

先确认新论文中的操作对象和关键差异，再借用案例的对应方式。外观相似不代表机制相同：MAC 的视图权重乘在扰动上，PA-Attack 的 token 权重作用于目标项，AD² 则在重组序列元素。实例有助解释，不构成效果证据。
