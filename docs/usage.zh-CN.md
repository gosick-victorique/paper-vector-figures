# paper-vector-figures：迁移与使用

本压缩包是当前skill的独立快照。解压后保留整个 `paper-vector-figures/` 文件夹，不要只复制SKILL.md。

## 包含什么

```text
paper-vector-figures/
  SKILL.md          主流程与参考入口
  agents/           Codex展示名称与默认调用提示
  references/       构图指导、原图、案例图片、四评委协议
  scripts/          可选SVG组件、评分汇总与报告脚本
```

参考图片已在包内。Python缓存不包含在内。三个历史案例中的本机实验目录已在导出副本中替换为通用说明，原安装不变。

此包迁移的是skill及其参考资源，不是整套研究工作区：本次聊天、持续目标、原始论文PDF、实验室HTML页面、所有逐轮评审和案例生成器没有整体打包。历史案例中提及的生成脚本文件名是研究记录，不是使用skill的必需依赖。使用新论文时需另提供论文或可访问的原文链接。

## 另一台电脑的Codex

按当前官方文档，个人skill文件夹放在：

- Windows：`C:/Users/<用户名>/.agents/skills/paper-vector-figures/`
- macOS/Linux：`~/.agents/skills/paper-vector-figures/`
- 只给某个仓库使用：`<仓库>/.agents/skills/paper-vector-figures/`

最终应为上述文件夹下直接包含 `SKILL.md`，避免多套一层同名目录。Codex通常自动发现；未出现时重启。当前来源机器使用 `.codex/skills`，迁移时以上述目标环境当前文档为准，不必复制来源机器的用户目录。

官方依据：[Build skills](https://learn.chatgpt.com/docs/build-skills)。

安装后，附上论文并发送：

> 使用 $paper-vector-figures，根据这篇论文绘制完整方法图。按内容组合2D和局部3D，输出可编辑SVG和预览。让四位独立评委实际看图，从美观、专业、方法解释、丰富程度评分，综合意见后最多重绘2次，保留前后对照。重点做设计，不做导出或格式检查。

图形承担主要解释，文字和公式作补充。已有模板时一并提供栏宽、可用高度或页面样式；没有模板时由skill声明暂定尺寸。交付包含建议插入宽高、主要字号与版面比例预览，四位评委先按该比例看图，再放大查看细节。

更新时用新版本的整个skill文件夹替换旧版；同一环境不要重复安装同名副本。

## 其他支持Agent Skills的工具

把同一个文件夹放进目标工具支持的skill目录，或按它的导入方式安装。目录位置和触发语法由该工具决定，不假定它识别Codex的路径或 `$` 语法。

可以明确要求：

> 读取paper-vector-figures/SKILL.md，按其中的相对链接读取需要的参考并实际查看参考图，然后执行论文方法图设计。将四评委协议映射到本环境可用的独立子代理工具；保持每位评委的新鲜上下文和相同评审包。

`agents/openai.yaml` 是Codex界面元数据，其他工具未必读取；核心流程在SKILL.md及references里。协议中的 `collaboration.spawn_agent` 是示例工具名，需要由目标环境的代理能力替换，复制文件本身不会赋予这些工具。

## 没有原生skill机制的聊天或代理环境

若能解压、读取文件和查看图片，可把解压文件夹放在其工作区，明确要求先读SKILL.md，再按需读取参考。如果只能上传文本，可以使用其构图提示与评审量尺，但参考图和代码执行能力不因此自动可用，也不等于完整安装。

四评委可由四个互不共享意见的新会话完成：给每位相同的图、图注与论文依据，再给不同角色；收齐四份JSON后由主会话综合。若做不到，明确记录独立评审未执行，不能由同一会话扮演四人冒充。

## 运行条件

- 核心设计：能读论文与参考文件、写SVG、实际查看生成图。看图预览工具由目标环境提供；浏览器、现有SVG预览器等均可，不依赖来源电脑的特定程序路径。
- 附带SVG组件及评分汇总脚本：Python 3，常规功能仅用标准库。PDF组件的reportlab为可选依赖，当前快速设计流程不要求安装或运行它。
- 独立评审：支持子代理/独立会话，并能把同一图片及论文提供给每位评委。只有多角色提示、没有独立执行能力时，达不到这项要求。
- 联网：提供完整论文和所需参考时可离线使用已打包资料；搜索新论文或补读线上来源时才需要网络。

迁移包未在另一台电脑或其他厂商工具上实际运行；打包不代表跨平台效果已验证。完整版本优先于删去图片的“纯提示词版”，因为视觉参考本来就是这个skill的重要组成。
