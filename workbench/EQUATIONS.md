# 公式

点击「插入 → LaTeX 公式」，输入 LaTeX，预览后添加到画板。提供分式、求和、矩阵和多行模板，可设置字号、颜色和独立／行内排版。

公式是独立的矢量组件，可移动、缩放、旋转和改色。双击公式、使用浮动工具栏「编辑公式」，或从右键菜单进入编辑器，可继续修改原始 LaTeX。修改支持撤销和重做；源码随画板自动保存。

字号为公式的基础字号；画板上的整体缩放会继续作用于修改后的公式。需要多行时使用 `aligned` 等数学环境。

渲染使用随应用附带的 MathJax 3.2.2，不需要联网或 API Key。输出为包含字形路径的 SVG。支持数学公式语法，不编译完整 LaTeX 文档。SVG 用于矢量展示，继续编辑源码请保留工作台项目。
