# Figure Studio

AI 协同论文绘图工作台，支持组件与图元编辑、素材选择和局部修改。

## 启动

需要 Node.js 22.13.0 或更新版本。在 PowerShell 中运行：

```powershell
cd workbench
npm ci
$env:FIGURE_SKILL_PATH = (Resolve-Path ..).Path
npm start
```

打开 http://127.0.0.1:4318/，在「AI 设置」配置 API 地址、Key、模型和思考强度。服务需支持 Responses API。

## 操作

- 新建空白画板，输入论文正文与提示词生成图片；已有草图和批注可一并参与生成。
- 分组、组件、图元三级选择，支持多选、移动、缩放、旋转、配色、锁定与撤销。
- 选择基础绘图工具后直接在画板绘制；双击文字编辑，Enter 换行，Ctrl+Enter 完成。
- 右键菜单提供对象操作和 AI 提问；选区意见可用于局部修改。
- 导入图片与 SVG，保存画板 JSON 和版本。
- 「文件 → 导入论文正文」支持 PDF、TXT 和 Markdown，预览后替换或追加正文，可撤销。
- 「文件 → 画板尺寸」设置单栏、双栏或自定义尺寸；可设宽 40–500 mm、高 30–500 mm。
- 「文件 → 检查图稿」列出可能的越界、小字号、文字重叠及低对比度问题，可定位到对象。
- 「文件 → 导出图稿」导出当前画板的 SVG、PDF 或 PNG；PNG 可选 150 / 300 / 600 DPI，PDF 保留矢量图形与文字。
- 「文件 → 下载完整项目备份」保存所有画板、版本、批注、正文和未提交意见；导入备份会追加画板，保留现有项目内容。
- 滚轮缩放，空格拖动平移；右侧按属性、素材、连线和 AI 设置分栏。

PDF 在本机提取文字，无需配置 AI；文件上限 25 MB，每次最多提取 100 页，默认提取前 100 页。预览保留来源页码，可调整页码范围。扫描件需要先做 OCR；双栏、公式和图注需人工核对。导入只保存正文，不保存原 PDF 和图片。TXT / Markdown 上限 2 MB，也支持直接粘贴正文。

AI 生成和选区修改使用独立提示词。结果会在浏览器中进行基础图稿检查；出现新增提示、越界或检查不完整时，保留预览供手动应用。顶部「查看结果」可以重新打开已关闭的结果窗口。工作台暂未接入 skill 的独立四评委执行流程。

## 项目保存与恢复

画板自动保存到当前浏览器来源的 IndexedDB，内嵌图片按内容去重；保留上一次成功保存的恢复副本。首次启动自动迁移旧版 localStorage 画板，确认写入新存储后才移除旧记录。刷新后保留所有画板和版本，撤销栈仍只在本次会话中可用。

顶部显示保存状态；保存失败可点击重试，仍失败时请下载完整项目备份。多窗口同时编辑时，旧窗口不能覆盖另一窗口已保存的内容；先备份该窗口的修改，再刷新并导入备份。浏览器存储可能被用户清除，完整项目文件适合长期备份和跨设备迁移。

默认画板为 180 × 111 mm。调整画板尺寸保留现有元素的位置、物理大小和字号；缩小时若内容越界会提示先调整内容，尺寸修改可以撤销，保存与 AI 校验均使用当前尺寸。

导出尺寸沿用当前画板设置；不含选框、控制点和批注标记。SVG 可继续使用矢量软件编辑；PDF / PNG 用于论文或演示。继续编辑图表数据与 LaTeX 源码请保留项目备份。PDF 中文字体使用系统的微软雅黑、苹方或 Noto Sans CJK；缺少字体或存在不支持的转换时会提示错误，可改用 SVG 导出。

移动选区按动画帧更新对象位置和绑定连线，拖动结束统一保存为一次撤销操作。复杂场景回归覆盖 1,002 个节点，检查移动时未改对象的 SVG 保持不变。旋转、缩放和结束拖动仍会重新渲染整图。

## 图稿检查与 AI 采纳

检查使用实际 SVG 几何和文字渲染，按出版尺寸计算字号。当前规则提示小于 6 pt 的文字、低于 3:1 的已知纯色背景对比度，以及可能重叠的文字区域；这些是排查阈值，不是期刊规范或质量认证。重叠按包围框估算，可能包含旋转文字等误报。公式路径、位图中的文字、复杂背景、语义和论文机制仍需人工核对。

每次最多检查 6,000 个 SVG 元素、1,200 处文字，显示最多 150 项问题；达到上限会明确标记结果不完整。检查不修改图稿。AI 结果的规则检查使用提交时的完整预览，下载任务记录时附带本次浏览器检查结果。

局部 AI 修改允许保留未选区域的新对象、编辑和批注。选区及其父层、相关批注、绑定连线两端或共享 SVG 定义发生变化时，会拒绝采纳并指出冲突；整图生成仍要求原画板保持一致。未选区域有变化时需要手动应用，预览仍是提交时的其他区域；应用只修改选区并接入撤销历史。

## 验证

`npm test` 运行模型、素材、图表和 Agent 的全部单元及接口测试；`npm run test:browser` 验证导出、迁移、备份恢复、PDF 按页导入、自定义画板、复杂场景拖动、图稿检查与选区冲突采纳等浏览器流程。Windows 使用已安装的 Edge；其他系统先运行 `npx playwright install chromium`。这些测试不调用真实模型。

连接配置见 [Agent 说明](agent/README.md)。第三方图标许可保留在 `external-icons/licenses/`。


## 自主绘图（阶段 1 / 2 / 3 / 4 / 5 / 6 / 7）

任务面板新增「执行方式 → 自主绘图 · 观察与修订」。Agent 可调用素材、组件、绑定连线、可编辑图表和公式、排版、渲染、检查与回滚工具，在独立草稿中反复修订后一次采纳。快速编辑仍保留。详见 [自主绘图使用与实现说明](AUTONOMOUS.md)。

自主模式现可开启「论文证据与独立评审」：关键对象绑定原文出处，四个隔离会话评审后驱动修订；当前版本通过后才允许提交。通过「文件 → 独立评审与证据」查看采纳后的证据和评审记录。

### 自主绘图可靠性与评测

自主任务支持失败/中断后从草稿继续，保存命令回执并复用同一快照的已完成评审。独立评审增加局部高清图和实际 PDF 导出预览；任务预算可调整。使用 `npm run eval:prepare` 生成固定合成评测任务，`npm run eval:live -- --case pipeline` 在已配置的本地服务上实际运行。详见 [AUTONOMOUS.md](AUTONOMOUS.md)。

自主绘图还支持按绑定连线进行流程分层排版，以及对照原文 CSV/TSV/Markdown 表格逐值核验图表数据；未核验数据会单独标明。详见 [第五阶段说明](AUTONOMOUS.md)。

绑定连线新增“自动避障”：在模块间自动寻找直角路径，移动后重新计算；受阻或影响锁定连线时回退。Agent 通过 `connect_objects` 使用同一实现。

图稿检查新增绑定连线交叉、共线重叠、穿过模块和文字的诊断。问题提供对象定位、局部预览区域和修复建议；新增问题暂停自动应用，Agent 可调整后重新检查。详见 [第六阶段说明](AUTONOMOUS.md#阶段-6可定位的连线诊断)。

连线面板新增“尝试修复所选连线”，Agent 可调用 `repair_connections`：默认保留端口和模块位置，比较候选路径并实际渲染复查，只有规则问题改善才一次应用；无改进保留原图。支持持久避让其他连线。详见 [第七阶段说明](AUTONOMOUS.md#阶段-7经过复查的连线修复)。
