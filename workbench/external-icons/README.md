## 使用方式

- `index.html` 可离线浏览，按中文用途、英文名称和来源搜索；点击图标打开 SVG。
- 原始 SVG 未描摹、未改色，按官方仓库的固定提交版本下载。清单记录每个文件的 URL、版本、SHA-256 和许可证。
- 图标用于对象、设备、状态或工具标识；盾牌、锁和机器人等通用符号不代替具体防御或学习机制。
- `simple-icons` 中的 20 个图标是品牌标识。清单保存已匹配的官方品牌来源和使用指南；图标的版权许可不等于品牌背书。
- 将素材复制到其他项目时，一并保留对应 `licenses/` 文件和来源记录。
- 当前完成素材下载和预览；尚未实现将外部 SVG 一键导入画板。
