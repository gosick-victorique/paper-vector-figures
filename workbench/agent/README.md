# AI 绘图接入

## 使用

1. 安装 Node.js 22 或更新版本。在工作台目录运行 `npm ci`。
2. 运行 `npm start`，或在 PowerShell 运行 `./start-agent.ps1`。
3. 打开 <http://127.0.0.1:4318/>。点击「生成图片」；已有图稿可选择组件后，在顶部入口切换为「修改选区」。
4. 在右侧「AI 设置」填写 API 地址和 API Key，点击「获取可用模型」，在模型输入框搜索并从列表选择，然后保存连接。也可手动填写模型名。已保存的 Key 可留空复用；更换 API 地址需要重新填写 Key。查询调用该地址下的 `GET /models`，不保存未提交的连接信息；列表不提供完整能力保证。模型和服务需兼容 Codex 的 Responses 调用、图像输入与结构化输出；仅支持 Chat Completions 的服务不能直接使用。
5. 输入文档正文、提示词与图片用途，点击「生成图片」。当前画板的组件、布局、批注和配色会一并发送；空画板从零生成。局部编辑使用「开始修改」。
6. 默认完成后自动放回画板、选中修改组件并展开图层。可关闭自动放回，改为比较后手动采纳。图元保持可编辑，并进入画板撤销历史。

API Key 使用 Windows DPAPI 当前用户范围加密，保存在 `%LOCALAPPDATA%/PaperFigureWorkbench/connection.json`，服务重启后自动恢复。不会将明文 Key 写入浏览器存储、任务、日志或图稿；「清除 Key」同时删除保存的凭据。也可以由运行服务的本机环境设置 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`FIGURE_MODEL`。不要将 Key 写进论文、修改意见或提交到 Git。

服务绑定 127.0.0.1；请求有来源和会话令牌校验。使用者明确配置的 API 服务会收到本次论文正文、图稿预览、场景结构与意见。连接设置保存成功仅表示配置完整，实际认证、模型能力和额度在运行任务时验证。

执行器通过 HTTP Responses 流式传输连接配置的 API，不要求兼容服务实现 WebSocket。思考强度在「AI 设置」保存；模型默认不发送强度覆盖，其他档位原样传入，不自动降档。模型是否支持该档位须以实际请求为准。HTTP 429 表示服务限制了请求，不能仅凭状态码认定 Key 无效或额度耗尽。

## 已有画板迁移

文件版和 HTTP 服务版的浏览器存储独立。在文件版右侧「导入 / 导出」下载 JSON，在服务版同一区域导入。导入保留对象、分组、批注和配色；历史版本与未保存意见不随迁移文件转移。导入可撤销。

## 工作范围

- 生成与局部修改均为快速任务，不执行四评委。
- 当前画板几何仍为 1200 × 740；论文名称、职责和正文可替换，正文可从 TXT/Markdown 导入。支持空白画板生成；整篇 PDF 导入尚未接入。
- 任务执行器使用 `@openai/codex-sdk`，API Key 认证。每次在独立工作目录和独立 Codex home 下启动，以结构化操作返回，不能直接写画板源文件。
- Skill 默认来自 `~/.codex/skills/paper-vector-figures`，可设置 `FIGURE_SKILL_PATH` 指向其他副本。任务保留使用的版本和主文件 SHA-256。
- 现有模板元数据随选区传入；尚无全素材库检索工具或外部图标自动导入。
- 现有分组和组件 ID 保持稳定；生成模式可新增 component 及独立 leaf，局部编辑模式仅新增 leaf。返回的 SVG 限静态内容，外部资源与主动内容会拒绝。
- 绑定连线自动跟随模块接口；普通 SVG 箭头需要一并选中后修改。
- 锁定限制由程序检查；不能通过父层移动绕过锁定子图元。不能删除选区根节点或有批注的对象。
- 采纳前比较场景、配色和批注的基础版本。运行期间若这些发生变化，结果只能查看和下载，需要重新提交，避免覆盖手工编辑。
- 支持取消和 15 分钟超时；刷新页面可恢复最近任务。服务重启后未完成任务标记中断，不自动重复调用。任务文件保存在 `.agent-jobs/`，不经静态文件路由公开。
- 没有自动进行设计复评；完成状态只表示 Agent 返回通过结构校验且成功渲染。视觉和科学准确性仍须查看结果。

## 模块

- `client.js`：连接设置、任务进度、前后比较、采纳及迁移。
- `server.mjs`：本地服务、任务生命周期、配置、持久化和接口。
- `runner.mjs`：SDK 适配器、明确的 skill 和论文输入、结构化输出。
- `patch-contract.js`：浏览器和后端共享的范围、锁定、层级及几何约束。
- `svg-safety.cjs` / `render.cjs`：SVG 检查及场景重建。

运行 `npm run test:agent` 检查范围、锁定、版本、XML、真实图稿渲染和 HTTP 生命周期。HTTP 测试使用明确标记的测试执行器，不调用真实模型。`node agent/sdk-transport-smoke.mjs` 可另外启动真实 SDK / CLI，对接本机测试 Responses 服务验证进程和传输链路，同样不调用真实模型。这些检查不代替浏览器交互验证或真实 API 联调。

接口依据：[OpenAI Docs — Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)。
模型发现：[OpenAI Docs — List models](https://developers.openai.com/api/reference/resources/models/methods/list)。

## 对象编辑

分组、组件、图元和多选均支持宽高（可锁定比例）、填充、描边、文字色、线宽、透明度及撤销。手动配色不再被整图色板覆盖。含多个几何的 AI 图元可用「拆分图元」拆开编辑；拆分保留当前世界坐标与原有绘制顺序，有批注或锁定时拒绝拆分。位图可调尺寸和透明度，填充/描边不改其像素。
