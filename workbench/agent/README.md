# AI 绘图接入

## 使用

1. 安装 Node.js 22.13.0 或更新版本。在工作台目录运行 `npm ci`。
2. 运行 `npm start`，或在 PowerShell 运行 `./start-agent.ps1`。
3. 打开 <http://127.0.0.1:4318/>。点击「生成图片」；已有图稿可选择组件后，在顶部入口切换为「修改选区」。
4. 在右侧「AI 设置」填写 API 地址和 API Key，点击「获取可用模型」，在模型输入框搜索并从列表选择，然后保存连接。也可手动填写模型名。已保存的 Key 可留空复用；更换 API 地址需要重新填写 Key。查询调用该地址下的 `GET /models`，不保存未提交的连接信息；列表不提供完整能力保证。模型和服务需兼容 Codex 的 Responses 调用、图像输入与结构化输出；仅支持 Chat Completions 的服务不能直接使用。
5. 输入文档正文、提示词与图片用途，点击「生成图片」。当前画板的组件、布局、批注和配色会一并发送；空画板从零生成。局部编辑使用「开始修改」。
6. 默认在基础图稿检查通过后自动放回画板，选中修改组件并展开图层。发现新增检查问题、越界、检查未完成或未选区域有新修改时，保留预览供手动采纳；顶部「查看结果」可重新打开结果。也可关闭自动应用。图元保持可编辑，并进入画板撤销历史。

API Key 使用 Windows DPAPI 当前用户范围加密，保存在 `%LOCALAPPDATA%/PaperFigureWorkbench/connection.json`，服务重启后自动恢复。不会将明文 Key 写入浏览器存储、任务、日志或图稿；「清除 Key」同时删除保存的凭据。也可以由运行服务的本机环境设置 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`FIGURE_MODEL`。不要将 Key 写进论文、修改意见或提交到 Git。

服务绑定 127.0.0.1；请求有来源和会话令牌校验。使用者明确配置的 API 服务会收到本次论文正文、图稿预览、场景结构与意见。连接设置保存成功仅表示配置完整，实际认证、模型能力和额度在运行任务时验证。

执行器通过 HTTP Responses 流式传输连接配置的 API，不要求兼容服务实现 WebSocket。思考强度在「AI 设置」保存；模型默认不发送强度覆盖，其他档位原样传入，不自动降档。模型是否支持该档位须以实际请求为准。HTTP 429 表示服务限制了请求，不能仅凭状态码认定 Key 无效或额度耗尽。

## 已有画板迁移

文件版、HTTP 服务版和桌面版的存储独立。新版本优先使用「文件 → 下载完整项目备份」和「导入项目备份」迁移所有画板、版本与未提交意见；导入会追加画板，保留现有内容。旧版单张画板 JSON 仍可导入，但不包含历史版本与未保存意见。

## 工作范围

- 默认快速编辑不执行独立评审；自主模式可启用论文证据与四个独立会话评审，详见 [自主绘图](../AUTONOMOUS.md)。
- 默认画板为 180 × 111 mm（1200 × 740 坐标单位），可在文件菜单调整到宽 40–500 mm、高 30–500 mm。任务、预览、导出和边界校验均使用当前尺寸。
- 正文可从 PDF / TXT / Markdown 导入。PDF 本地按页提取，预览后写入正文，不调用模型；单文件最多 25 MB、每次最多 100 页。扫描件须先做 OCR，双栏和公式需核对。支持空白画板生成。
- 任务执行器使用 `@openai/codex-sdk`，API Key 认证。每次在独立工作目录和独立 Codex home 下启动，以结构化操作返回，不能直接写画板源文件。
- Skill 默认来自 `~/.codex/skills/paper-vector-figures`，可设置 `FIGURE_SKILL_PATH` 指向其他副本。任务保留使用的版本和主文件 SHA-256。
- 自主模式可检索、预览、插入工作台模板和外部图标，并保留来源元数据。
- 生成任务同时提供嵌套参考案例与参考图片。场景里的内嵌图片转成任务目录中的独立文件，提示词只携带资源标识；返回操作里的已有标识会恢复为原图后再校验。
- 现有分组和组件 ID 保持稳定；生成模式可新增 component 及独立 leaf，局部编辑模式仅新增 leaf。返回的 SVG 限静态内容，外部资源与主动内容会拒绝。
- 绑定连线自动跟随模块接口；普通 SVG 箭头需要一并选中后修改。
- 锁定限制由程序检查；不能通过父层移动绕过锁定子图元。不能删除选区根节点或有批注的对象。
- 采纳前检查选区、父层、相关批注、绑定连线依赖、共享 SVG 定义、整图配色和画板尺寸。未选区域的独立修改可在手动采纳时保留；选区依赖变化会明确拒绝采纳。整图生成仍要求完整场景和批注未变。校验在画板 API 中同步执行，避免界面校验和写入之间覆盖新修改。
- 支持取消和 15 分钟超时；刷新页面可恢复最近任务。服务重启后未完成任务标记中断，不自动重复调用。任务文件保存在 `.agent-jobs/`，不经静态文件路由公开。
- 服务端完成状态表示 Agent 返回通过结构校验且成功渲染。浏览器随后按实际 SVG 检查越界、小字号、文字重叠和纯色背景对比度；报告会区分未判断的复杂样式和达到检查上限的情况。这些规则不执行独立设计评审，不验证论文事实或机制。

## 模块

- `client.js`：连接设置、任务进度、前后比较、采纳及迁移。
- `server.mjs`：本地服务、任务生命周期、配置、持久化和接口。
- `document-import.mjs` / `document-worker.mjs`：独立工作线程中的 PDF 提取，支持超时、取消和无文字提示。
- `runner.mjs`：SDK 适配器、明确的 skill 和论文输入、结构化输出。
- `adoption.js`：局部任务采纳时的依赖比较与冲突说明。
- `patch-contract.js`：浏览器和后端共享的范围、锁定、层级及几何约束。
- `svg-safety.cjs` / `render.cjs`：SVG 检查及场景重建。

运行 `npm test` 检查范围、锁定、版本、XML、图稿渲染、存储恢复、导出和 HTTP 生命周期；`npm run test:agent` 仅运行 Agent 目录下的测试。`npm run test:browser` 验证实际浏览器工作流。测试使用明确标记的测试执行器，不调用真实模型。`node agent/sdk-transport-smoke.mjs` 可另外启动真实 SDK / CLI，对接本机测试 Responses 服务验证进程和传输链路。这些检查不代替真实 API 联调。

接口依据：[OpenAI Docs — Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)。
模型发现：[OpenAI Docs — List models](https://developers.openai.com/api/reference/resources/models/methods/list)。

## 对象编辑

分组、组件、图元和多选均支持宽高（可锁定比例）、填充、描边、文字色、线宽、透明度及撤销。手动配色不再被整图色板覆盖。含多个几何的 AI 图元可用「拆分图元」拆开编辑；拆分保留当前世界坐标与原有绘制顺序，有批注或锁定时拒绝拆分。位图可调尺寸和透明度，填充/描边不改其像素。


## 自主绘图（阶段 1 / 2 / 3 / 4 / 5 / 6 / 7）

任务面板新增「执行方式 → 自主绘图 · 观察与修订」。Agent 可调用素材、组件、绑定连线、可编辑图表和公式、排版、渲染、检查与回滚工具，在独立草稿中反复修订后一次采纳。快速编辑仍保留。详见 [自主绘图使用与实现说明](../AUTONOMOUS.md)。

阶段 3 已加入 `get_evidence`、`bind_evidence`、`review_figure`、`get_review`。每轮最多四个独立模型调用、最多三轮；评审失败或阻断问题不会自动放行。报告、证据和检查点保存在任务目录，采纳后随项目备份。

阶段 4 增加 `/api/jobs/:id/resume`（原任务 baseRevision）、持久命令回执、逐角色保存与失败角色重试、高清分区图、PDF 导出后重新渲染、执行预算和 token 汇总。`npm run eval:prepare` 准备固定合成任务，`npm run eval:live` 使用本地服务已配置的模型实际评测；不会采纳到用户画板。

阶段 5 新增 `analyze_graph`、`layout_graph`、`check_evidence`，共 24 个绘图工具。已有绑定连线驱动分层布局，图表引用支持原表行列映射与逐值核验；非结构化来源显式保留未核验状态。新证据评审记录为 schema 2，读取兼容 schema 1。

绑定连线现支持 `route: "avoid"` 和 `clearance: 12` 自动避障；保留端口，移动障碍物后重新走线。无路可走或影响锁定连线时拒绝整个修改。详见 `AUTONOMOUS.md` 的连线自动避障说明。

阶段 6 扩展 `check_figure`：绑定连线交叉、共线、穿越图形/文字的实际渲染检查，返回 `ids`、`region`、`magnitude` 和 `suggestion`。`region` 可直接传给 `render_region`；限制与跳过项明确返回。用 `node agent/autonomous-transport-smoke.mjs --connections` 验证观察、修复、复查与提交链路。

阶段 7 新增第 25 个工具 `repair_connections`，批量尝试修复选中连线；实际渲染复查后才应用，无改动保留 revision，成功后仍需观察/检查及更新过期证据。`avoidConnections` 支持持久避让非共用端点的其他连线。`node agent/autonomous-transport-smoke.mjs --repair` 验证完整调用链。
