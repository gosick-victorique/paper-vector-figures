# Paper Vector Figures

根据论文机制设计信息丰富、技术准确、可编辑的矢量方法图。按内容组合二维与局部三维，通过四位独立评委的反馈优化图稿。

面向计算机科学论文，可用于方法图、系统架构图和算法示意图；实验数值图应使用科学绘图工具。

## 能做什么

- 从方法、公式与图注提炼对象、操作、约束和更新，保持来源与示意的区别。
- 以实际关系选择2D、局部3D、矩阵、空间层次和局部展开。
- 生成可编辑SVG与可看的预览。
- 由视觉总监、领域审稿人、论文图编辑、跨领域读者分别评审美观、专业、方法解释、丰富程度。
- 综合意见按瓶颈重绘，保留旧版、实际评分和未解决问题。

## 安装到Codex

下载本仓库或克隆，保持文件夹内直接包含 `SKILL.md`。将整个文件夹命名为 `paper-vector-figures`，放到：

| 使用范围 | 位置 |
|---|---|
| Windows个人使用 | `C:/Users/<用户名>/.agents/skills/paper-vector-figures/` |
| macOS/Linux个人使用 | `~/.agents/skills/paper-vector-figures/` |
| 当前仓库使用 | `<仓库>/.agents/skills/paper-vector-figures/` |

Codex通常自动发现；未出现时重启。安装位置依据[官方文档](https://learn.chatgpt.com/docs/build-skills)。不要同时安装多个同名副本。

附上论文后使用：

```text
使用 $paper-vector-figures，根据这篇论文绘制完整方法图。
按内容组合2D和局部3D，输出可编辑SVG和预览。
启动四位独立评委，综合意见后最多重绘2次，保留前后对照。
专注设计，不做导出或格式检查。
```

## 在其他环境使用

支持Agent Skills的工具可按其安装方式使用本文件夹。其他代理可以从 [SKILL.md](SKILL.md) 开始，按相对链接读取必要参考并实际查看图片。

完整评审需要目标环境提供读文件、看图和独立子代理/会话能力；协议里的工具名称需要映射到该环境。技能文件本身不提供模型服务。不能由同一会话扮演四人冒充独立评审。

附带SVG组件与评分汇总脚本通常只需Python 3标准库；PDF组件的reportlab为可选依赖。预览工具由目标环境提供。

详细迁移、能力要求和调用方法见[使用说明](docs/usage.zh-CN.md)。
